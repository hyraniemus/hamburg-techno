# 📚 News-Quellenattribution Guide

## Problem: "Hamburg Startups suchen AI-Post-Production-Freelancer"

### ❌ Das war FALSCH dargestellt:
```
"💼 Hamburg-Startups suchen AI-Post-Production-Freelancer"
Quelle: WebSearch
```

**Problem:** Zu vage, keine Verifizierung, könnte erfunden sein.

---

## ✅ So sollte es sein:

### **Option A: TREND (Begründete Beobachtung)**
```
💼 **Trend: Wachsende Nachfrage nach AI-Post-Prod-Freelancern in Hamburg**
- [27 AI Startups in Hamburg 2026](https://www.seedtable.com/best-ai-startups-in-hamburg)
- [AI.HAMBURG Ecosystem](https://startupcity.hamburg/startups-ecosystem/ai-hamburg) mit 69+ Startups
- Freelancer-Boom: [Upwork AI Developer Hiring](https://www.upwork.com/hire/ai-developers/)
- **Fazit:** Dein Profil (Media Composer → AI-Tools) passt in den Markt
- **Action:** LinkedIn/Xing durchsuchen: #AIVideo #Hamburg
```

### **Option B: FACT (Konkrete Job-Listing)**
```
💼 **Job Alert: XYZ Startup in Hamburg sucht AI Video Editor**
- **Unternehmen:** [Company Name](link)
- **Position:** AI-Post-Production Specialist
- **Details:** [Job-Link](job-url)
- **Dein Vorteil:** Media Composer + ComfyUI-Skills ideal
```

### **Option C: KEINE NEWS (Besser weglassen)**
```
❌ Behauptung ohne Quelle → NICHT IN NEWS AUFNEHMEN
```

---

## 📋 Checklist für jede News-Aussage

Bevor du etwas hinzufügst, frage dich:

1. **Ist das ein FACT (konkrete News)?**
   - Ja → Offizielle Quelle (Blog, GitHub Release, Press Release) ✅
   - Nein → Gehe zu 2.

2. **Ist das ein TREND (allgemeine Beobachtung)?**
   - Ja → Min. 2-3 Belege angeben (z.B. Job-Boards, Reports)
   - Nein → NICHT in News aufnehmen ❌

3. **Habe ich einen direkten Link?**
   - Ja → `[Text](URL)` verwenden
   - Nein → Nicht posten, oder: "Basierend auf [Quelle1], [Quelle2]"

## 🔴 Rote Flaggen (NICHT verwenden)

| Problem | Beispiel | Fix |
|---------|----------|-----|
| Zu vage | "Startups suchen Freelancer" | "27 AI Startups in Hamburg (Seedtable 2026)" |
| Erfunden | "Claude Code Video Toolkit v2.1" | GitHub verifizieren |
| Alte News | "Feature von Februar" | Datum + "Archive" label |
| Social Media Hype | "X Post mit 100 Likes sagt..." | Nur wenn von offiziellem Account |
| Keine Quelle | "Ich habe gehört..." | NICHT POSTEN |

---

## 📊 Quelle-Priorität (verwende diese Ordnung)

1. **🏢 Official** (80% Gewicht)
   - Blackmagic Blog, NVIDIA Official, Anthropic, GitHub Releases
   
2. **📰 Tech Press** (60% Gewicht)
   - TechCrunch, CG Channel, Newsshooter, MacRumors
   
3. **👥 Community** (40% Gewicht)
   - Reddit (verifizierte Posts), Hacker News (top 30)
   - Twitter/X (nur von verified Accounts oder CEOs)

4. **⛔ Keine Quellen**
   - Blogs ohne Autor
   - Social Media Posts mit <100 Likes
   - "Ich glaube, dass..."

## 📝 Template für deine Notion-Einträge

```markdown
## [Tool Name] – [Update]

**Was:** [1 Satz]

**Quelle:** 
- Offizielle: [Name](Link)
- Referenz: [Name](Link)

**Für dich relevant:**
- [Punkt 1]
- [Punkt 2]

**Action:**
- [Konkrete nächste Schritte]

**Verifiziert:** ✅ [Ja/Nein] – Datum & Checker
```

---

## 🔄 Regelmäßige Audits

Jede Woche: Überprüfe 3 alte News-Einträge auf Source-Validity.
- Link broken? → Update oder archive
- Keine Quelle? → Nachrecherchieren oder löschen
- Info veraltet? → Mit Aktualgesamtstand ersetzen
